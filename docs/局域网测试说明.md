# 局域网测试说明

用自己的电脑当临时服务器，手机和电视盒子连同一个 Wi-Fi 来测试。

## 一、电脑上启动服务

1. 安装 [Node.js](https://nodejs.org/) 20 或更高版本。
2. 在项目根目录运行：

   ```bash
   npm run setup     # 第一次：安装依赖
   npm run lan       # 构建网页并启动服务
   ```

3. 启动后，终端里会显示遥控页地址、大屏页地址，以及遥控页的二维码，例如：

   ```
     遥控页（手机）： http://192.168.1.5:18630/
     大屏页（电视）： http://192.168.1.5:18630/tv/
   ```

4. Windows 第一次运行时会弹出防火墙提示，请勾选“专用网络”并允许。如果当时点了取消，到“Windows 安全中心 → 防火墙 → 允许应用通过防火墙”里放行 Node.js。Mac 会有类似的提示，选择“允许”。
5. 测试期间请关闭电脑的自动休眠。

## 二、手机

用手机相机扫终端里的二维码，在系统浏览器里打开遥控页。不需要登录，打开就能操作。

用微信扫码打开内网 IP 地址时，可能会被拦截或弹出风险提示，所以测试时建议用相机扫码。

## 三、电视

**方式 A：安装局域网测试版 APK（推荐）**

1. 把 `翻牌钟大屏-局域网测试版.apk` 装到盒子上：可以用 U 盘拷过去，用盒子的文件管理器安装；也可以执行 `adb install 文件名.apk`。
2. 打开“翻牌钟大屏（测试）”，在设置页填写终端里显示的地址，例如 `192.168.1.5:18630`，然后点“连接”。
3. 电视上会显示待机页：一个二维码和本机编号。用微信或手机相机扫这个二维码，在弹出的“这块屏幕显示哪场比赛？”里选一场比赛（也可以当场新建一场），给屏幕起个名字，点“开始显示”。

以后电脑 IP 变了，按遥控器菜单键（或 2 秒内连按 3 次返回键）就能重新填写地址。

**方式 B：不装 APK，只看画面**

用盒子自带的浏览器，或者另一台电脑的浏览器，打开终端里显示的大屏页地址。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 手机或电视打不开页面 | 确认连的是同一个 Wi-Fi；访客网络和一些公司网络会开启“设备隔离”，这时可以换成主网络，或者用电脑开热点 |
| 电脑能打开，手机打不开 | 多半是防火墙拦住了，按第一节第 4 条放行 |
| 电视显示“网络连接失败” | 检查电脑上的服务是否还在运行、电脑 IP 有没有变；IP 变了就在电视上重新填写地址 |
| 想固定电脑的 IP | 在路由器里给这台电脑设置 DHCP 地址保留 |
| 想清空测试数据 | 停止服务，删除 `server/data` 目录，再重新启动 |
| 想换端口 | 用 `PORT=18631 npm run lan` 启动（Windows PowerShell 写法：`$env:PORT=18631; npm run lan`），电视上的地址也改成 `IP:18631` |
