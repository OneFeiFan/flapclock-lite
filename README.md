# 翻牌钟简化版（flapclock-lite）

扑克锦标赛计时大屏：**电视只负责显示，所有控制和配置都在手机网页上完成**。电视端用安卓外壳（APK）加载大屏页。

从翻牌钟 v1.1 拆分而来，删掉了 PC 控制台、选手页、语音、人数统计、奖金表、手对手和撤销。

## 功能

- **大屏（`/tv/`）**：
  - 翻片倒计时，以及盲注和前注。
  - 盲注结构表：当前级保持在中间，换级时平滑滚动。
  - 下一级、距休息。
  - 常驻信息栏。
  - 公告走字灯：一次性公告和常驻循环文字，多屏同步滚动。
  - 截止买入休息。
  - 升级闪屏、防烧屏微移。
  - 升盲语音播报：开赛、升级、休息、截止买入、比赛结束，以及剩一分钟提醒；每块屏幕可单独开关（手机首页的屏幕设置），播报内容在比赛页的“语音播报”里选。语音包在 `web/public/voice/`。
- **手机遥控（`/`）**：
  - 首页管理比赛、盲注方案（最多 5 套）和屏幕；扫电视上的二维码即可绑定。
  - 比赛页有当前倒计时和播放器式控制：长按切换级别，拖动进度条设定剩余时间。
  - 编辑常驻信息栏和走字灯，查看操作日志。
- **盲注结构编辑页**：
  - 最多 50 行，支持截止买入休息。
  - 添加级别时自动按涨幅推算。
  - 进行中的比赛也能修改，已开始的级别会锁定。
- **多屏**：一台服务器可以同时运行多场比赛，每块屏绑定其中一场；同一场比赛的多块屏精确同步。

## 快速开始（局域网测试）

```bash
npm run setup   # 安装依赖（第一次）
npm run lan     # 构建网页并启动；终端里会显示地址和遥控页二维码
```

默认端口是 **18630**，可以用 `PORT=…` 修改。完整步骤见 [docs/局域网测试说明.md](docs/局域网测试说明.md)。

## 正式部署

见 [docs/正式部署说明.md](docs/正式部署说明.md)。部署脚本在 `deploy/`：填好 `deploy/.env` 后跑一条 `node deploy/deploy.mjs`，它会打包源码、在服务器上构建镜像、起容器、装边缘 vhost，最后自动跑完服务器侧和公网侧两套自检。

## 目录

| 路径 | 内容 |
|---|---|
| `server/` | Node 服务：赛事逻辑、盲注方案库、实时通道、REST 接口 |
| `shared/` | 前后端共用的计时引擎（`clock.mjs`）与结构规则（`structure.mjs`） |
| `web/` | Vue 2.7 网页：大屏、手机遥控、盲注编辑页；legacy 构建兼容安卓 6 的老内核 |
| `tv-android/` | 电视安卓外壳：正式版和局域网测试版，见 [tv-android/README.md](tv-android/README.md) |
| `deploy/` | 一键部署脚本（`deploy.mjs`）、Docker 镜像定义与编排、边缘 vhost 模板、自检脚本 |
| `docs/` | 接口与实时协议（`protocol.md`）、局域网测试说明、正式部署说明 |

## 开发

```bash
npm test                 # 服务端测试：计时引擎与后端逻辑
npm run dev:server       # 终端一：服务端，端口 18630
npm run dev:web          # 终端二：前端开发服务器，接口自动转发到 18630
```

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `18630` | 服务端口 |
| `HOST` | `0.0.0.0` | 监听地址。正式部署跑在容器里、由边缘网关从 docker 网络访问，保持 `0.0.0.0` |
| `DATA_DIR` | `server/data` | 数据目录（JSON 文件） |

## 注意

目前不需要登录：能访问这个地址的人都能操作。局域网测试没有问题；部署到公网时，请按正式部署说明第十节加上访问控制。
